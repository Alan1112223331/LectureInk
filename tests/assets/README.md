# Synthetic speech fixture

`speech.wav` is synthesized from the following fixed text using the Windows speech synthesizer. It is not microphone input, a lecture recording, or a user's voice.

> This is a synthetic speech sample for testing voice activity detection. There is no personal information in this recording.

It is used only for normal-volume, low-volume and speech-followed-by-silence tests. No network request is needed to run these tests.
