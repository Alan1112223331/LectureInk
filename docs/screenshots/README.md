# Interface screenshots

These screenshots show the actual LectureInk v0.1 Qt interface with manually prepared demonstration sentences about machine learning. They are illustrations of the interface, not a live translation benchmark.

- `bilingual.png`: continuous bilingual transcript, topic and glossary.
- `live-preview.png`: stable transcript plus a provisional sentence in the preview panel.
- `chinese.png`: Chinese-only transcript with a larger font and microphone input selected.

All lecture text is invented demonstration content. Generic device names replace hardware details. No real recording, personal transcript, account credential or local file path appears in the images.
